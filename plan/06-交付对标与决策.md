## 三、风险登记

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| sqlglot API 漂移（30.x 已把 schema 改必填） | 内核崩 | pyproject 钉 `>=30.20,<31`；升级必须重跑五条 golden |
| 自研 scope walker 召回不足 | 召回 <85% | 未召回必须落 unknown + reason code（不静默），先保精确率 100%（D7） |
| 把 M2/M3 做成 demo 级 | 与 FlowScope 无区别（D3） | 三条硬门禁（精确率/零静默/golden）每里程碑收尾跑 |
| 零静默门是空判据（写了但测不到违规） | 静默丢弃回归且无人发现 | 阳性对照用例 `test_zero_silence_gate_catches_violation` + 收尾变异验证（关掉 `no_source_columns` 后门必须红，退出码 4） |
| 无远端期间宣称 CI 绿 | 自相矛盾 | 措辞固定"本地等价校验（未接远端，CI 待首推验证）" |
| 普查从边集反推写者/读者 → `write_only`/`orphan` 判反 | 全量常量写语句（边集为空）丢失写者；纯 `SELECT` 读者消失 | 写者/读者一律取语句台账（`write_targets` / `reads`），§4.8 规则 1–2；`test_write_only_constant_write_still_counts_as_writer` + `test_pure_select_is_reader_but_not_writer` 锁死，收尾变异验证（改成从边集取 → 必红） |
| 语料注释与实测不符（`50_*` 注释称 `raw_orphan` 无人读，实际 `51_*` 读了它） | 按注释写断言会把正确实现判红 | 断言以实测为准（`raw_orphan` 写 1 读 1，两边都不落）；真实语料的 `write_only` 植入项是 `stage_hot`；g4 golden 是权威植入项（`HANDOFF-M4 §四`） |
